# 复旦：程序设计

## 课程简介

- 所属大学：复旦大学
- 课程代码：CS10004
- 学分/学时：4 学分 / 90 学时
- 修读要求：必修（学科基础）
- 任课教师：杨帆
- 课程难度：🌟🌟

复旦大学的程序设计课程主要讲授C语言的入门知识，每周包括理论课和上机课。杨帆老师的课有一次期中、一次期末前的上机考试以及最后统一的纸质期末考。上机题目前几年都是哈希表，对于没有接触过的同学现场用指针完整无误的写出来还是有一定难度的。杨帆老师讲话很温柔，容易睡着（）但是ppt还是讲的比较清楚有条理的。学有余力的同学可以期末考试前刷一刷leetcode上面链表的题。

## 课程资源
- 教材：夏宽理《C语言程序设计》
