# 复旦：线性代数

## 课程简介

- 所属大学：复旦大学
- 课程代码：CS10003（2025 培养方案）/ COMP120004（2021 方案）
- 先修要求：无
- 编程语言：无
- 任课教师：张祥朝等
- 课程难度：🌟🌟🌟

这门线性代数主要是给信息类专业（如计算机、微电子等）的同学在大一上学期开设的线性代数，其他专业的同学上的是春季学期开设的线性代数（理工版）。课程按照行列式、矩阵、线性方程组、线性空间、线性变换、特征值与特征向量、二次型、补充内容（Jordan标准型与矩阵分解）的顺序展开。开设本课程的大多数老师使用的是复旦版的线性代数教材，阚海斌老师使用的是浙大版的（往届还会免费给同学们发书）。张祥朝老师的课会比较偏重一些定理的证明，期中考试也会涉及到不少课上讲过的证明；课上也会穿插一些数学史的知识，让枯燥的线性代数稍微有意思了一点（或许）。课上也会讲一些几何理解，但还是搭配3b1b的线性代数视频使用更好。
