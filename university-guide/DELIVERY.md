# 交付清单

## 可直接使用

- `mkdocs.yml` 与 `requirements.txt`：安装依赖后可严格构建静态站点；PR 不提交 `site/` 构建产物。
- `docs/`：站点 Markdown 源文档，包含现站审计、自由探索路线、56 能力页、6 方向路线、复旦映射、实施计划和验收报告。
- `data/`：可机器读的 56 能力、112 视频、6 路线和 56 课程映射。
- `scripts/`：数据校验、页面生成、构建后内链/响应式结构检查和外链检查。
- `reports/`：上游盘点、外链记录、12 项内容抽查、界面验收边界与机器可读验收结果。

## 核心数字

- 32 个公共推荐能力 + 每路线 4 个专业推荐能力；可按项目缺口自由选取。
- 56 项主资源 + 56 项备选资源；全部有精确章节、时长、评分、练习和核验日期。
- 六条路线覆盖 17 个原站方向；不设学期配额或强制年级顺序。
- 75 个静态 HTML 已通过严格构建与全部内链/锚点检查。
