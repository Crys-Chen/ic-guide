## 已通过的离线检查

`python scripts/check_site.py` 在最终严格构建结果上通过，证据如下：

- 75 个 HTML 均含移动端 `viewport`。
- 全部站内页面、资源、内部链接和锚点可解析；检查同时发现并修复了资源表原先指向 `.md` 源文件的 112 个错误链接。
- 首页、能力页、路线页和资源索引四类代表页面均存在。
- 资源表恰有 112 行，每行都有建议窗口、方向、主/备选、语言、时长、来源和搜索文本属性。
- 五个建议窗口、公共/17 方向、主/备选、语言、四档时长和来源类型的筛选选项与 YAML 一致。
- 资源表容器有横向滚动和触摸惯性滚动；44.9rem 以下筛选面板改为双列，关键词与计数占满整行。
- 无 JavaScript 时完整资源表仍可阅读；脚本加载后使用 `hidden` 逐行筛选，并提供结果计数与重置。

## 未伪装为通过的项目

本执行环境禁止浏览器打开本地 `file://` 页面，同时不允许绑定本地预览端口，因此无法保存真实窄屏截图或执行一次浏览器点击回归。该限制不等于页面失败，但发布前仍建议在可启动本地服务器的环境补做视觉确认：

```bash
mkdocs serve
```

建议视口为 390×844 和 768×1024，依次检查首页、`能力点/ANA-03/`、`专业路线/T-ANA/`、`视频资源/`；在资源页组合选择“方向探索与深化”、主资源和一个方向，确认计数、重置与横向滚动。
