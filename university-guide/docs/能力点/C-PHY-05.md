# 集成电路工艺

- 能力 ID：`C-PHY-05`
- 类型：公共能力
- 修读要求：公共推荐
- 建议窗口：IC 公共核心（可按兴趣提前或延后）
- 所属领域：物理与器件
- 参考投入：24 小时（不是学期配额）
- 先修能力：[半导体器件](./C-PHY-04.md)

## 学习成果

- 能说明晶圆制备、氧化、光刻、掺杂、刻蚀、沉积和平坦化的作用与顺序
- 能从截面和版图推断关键工艺步骤、设计规则与主要缺陷来源
- 能连接工艺波动、器件参数、良率和可靠性

## 验收

### 产物

一份从简化 CMOS 版图到工艺截面的流程卡，含关键控制参数和失效模式清单

### 合格标准

流程卡含不少于 8 个有序工艺步骤且每步截面与材料变化一致；至少列出 5 个失效模式，并为每项给出可测控制量或检查方法；版图层与最终截面可相互追踪。
