# 线性代数

- 能力 ID：`C-MATH-02`
- 类型：公共能力
- 修读要求：公共推荐
- 建议窗口：基础工具箱（可按兴趣提前或延后）

## 学习成果

- 能用矩阵、子空间、秩和线性变换表达线性系统
- 能求解线性方程组并解释特征值、特征向量和正交投影的工程意义
- 能用分解方法判断解的存在性、稳定性与数值敏感性

## 验收

### 产物

一个用 Python 求解节点方程并以特征值分析二阶系统模态的可复现实验笔记

### 合格标准

节点方程归一化残差不超过 1e-8；特征分解重构相对误差不超过 1e-6；在干净环境中从头运行可生成全部数值与图表。
