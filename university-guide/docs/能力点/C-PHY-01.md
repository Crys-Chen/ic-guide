# 电磁学

- 能力 ID：`C-PHY-01`
- 类型：公共能力
- 修读要求：公共推荐
- 建议窗口：基础工具箱（可按兴趣提前或延后）
- 所属领域：物理与器件
- 参考投入：24 小时（不是学期配额）
- 先修能力：[微积分与工程建模](./C-MATH-01.md)

## 学习成果

- 能用电场、电势、磁场和 Maxwell 方程解释集总模型的适用边界
- 能计算典型导体、介质和磁路结构中的场、能量与边界条件
- 能定性判断寄生、电磁耦合和传播效应

## 验收

### 产物

一份平行板电容和传输互连的场量推导、数量级估计及仿真对照报告

### 合格标准

场量单位、方向和至少 2 个边界条件全部正确；解析数量级与仿真结果相差不超过 10%；能依据尺寸与波长给出集总或分布模型选择并列出至少 2 种寄生效应。
