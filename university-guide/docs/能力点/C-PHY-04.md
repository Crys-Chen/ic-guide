# 半导体器件

- 能力 ID：`C-PHY-04`
- 类型：公共能力
- 修读要求：公共推荐
- 建议窗口：IC 公共核心（可按兴趣提前或延后）
- 所属领域：物理与器件
- 参考投入：26 小时（不是学期配额）
- 先修能力：[半导体物理](./C-PHY-03.md)、[电路分析](./C-CIR-01.md)

## 学习成果

- 能由物理机制解释 PN 结、二极管、BJT 和 MOSFET 的 I-V/C-V 特性
- 能选择器件工作区并建立适合电路分析的小信号或大信号模型
- 能识别短沟道、击穿、速度和功耗等非理想效应

## 验收

### 产物

一份 MOS 电容与 MOSFET 特性提取报告，包含模型、曲线、参数和偏差解释

### 合格标准

正确标出积累、耗尽、反型及 MOSFET 三个主要工作区；从曲线提取阈值电压、跨导和输出电阻，重复拟合偏差不超过 10%；说明至少 3 种非理想效应。
