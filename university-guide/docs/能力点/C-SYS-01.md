# C 与 Python 编程

- 能力 ID：`C-SYS-01`
- 类型：公共能力
- 修读要求：公共推荐
- 建议窗口：入门与试做（可按兴趣提前或延后）

## 学习成果

- 能用 C 编写包含指针、结构体、动态内存和文件 I/O 的小程序
- 能用 Python 进行数组计算、数据处理、绘图与自动化
- 能通过调试器、测试和代码风格检查定位并修复问题

## 验收

### 产物

一个含 C 命令行程序、Python 分析脚本、测试和使用说明的公开可复现仓库

### 合格标准

C 代码以 -Wall -Wextra 编译零警告并通过 AddressSanitizer；C/Python 合计不少于 20 个自动测试且全部通过；干净环境按 README 可一条命令生成结果图。
