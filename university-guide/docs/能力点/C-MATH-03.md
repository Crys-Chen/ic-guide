# 概率统计

- 能力 ID：`C-MATH-03`
- 类型：公共能力
- 修读要求：公共推荐
- 建议窗口：基础工具箱（可按兴趣提前或延后）
- 所属领域：数学
- 参考投入：22 小时（不是学期配额）
- 先修能力：[微积分与工程建模](./C-MATH-01.md)

## 学习成果

- 能使用条件概率、随机变量、常见分布、期望和方差分析不确定性
- 能从样本估计参数、构造置信区间并检验基本假设
- 能区分相关与因果并正确解释噪声和工艺波动数据

## 验收

### 产物

一份基于器件参数样本的分布拟合、置信区间和蒙特卡洛良率分析报告

### 合格标准

使用固定随机种子和不少于 10000 次蒙特卡洛样本；给出 95% 置信区间；模拟良率与解析或重采样基准相差不超过 2 个百分点，并说明检验假设。
