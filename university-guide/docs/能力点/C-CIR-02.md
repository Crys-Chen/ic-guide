# 模拟电子技术

- 能力 ID：`C-CIR-02`
- 类型：公共能力
- 修读要求：公共推荐
- 建议窗口：基础工具箱（可按兴趣提前或延后）
- 所属领域：电路与信号
- 参考投入：26 小时（不是学期配额）
- 先修能力：[电路分析](./C-CIR-01.md)、[电磁学](./C-PHY-01.md)

## 学习成果

- 能分析二极管、BJT、MOSFET 放大与开关电路的偏置和小信号性能
- 能解释反馈、稳定性、频率响应、噪声和失真的基本权衡
- 能完成运算放大器接口电路的设计、仿真和测量

## 验收

### 产物

一个满足增益、带宽和摆幅指标的两级放大器设计包，含计算、仿真和实测

### 合格标准

预先冻结的增益、带宽、摆幅和功耗指标全部通过；实测直流偏置与仿真相差不超过 5%，增益不超过 1 dB、带宽不超过 10%；报告探头和负载影响。
