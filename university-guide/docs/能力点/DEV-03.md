# 硅光器件与光子集成

- 能力 ID：`DEV-03`
- 类型：专业能力
- 修读要求：路线推荐
- 建议窗口：方向探索与深化（可按兴趣提前或延后）
- 所属领域：器件与制造
- 参考投入：28 小时（不是学期配额）
- 先修能力：[线性代数](./C-MATH-02.md)、[电磁学](./C-PHY-01.md)、[半导体器件](./C-PHY-04.md)、[先进 MOS 器件与工艺协同](./DEV-01.md)

## 学习成果

- 计算平板/条形波导的模式、有效折射率与传播损耗
- 设计耦合器、MZI、环形谐振器以及基本调制和探测单元
- 使用版图与电磁/电路模型建立可制造的硅光链路

## 验收

### 产物

一个含波导、耦合器和 MZI 或环形谐振器的版图、仿真与测试计划

### 合格标准

给出可复现模型，报告插入损耗、消光比/品质因数和至少两项工艺容差
