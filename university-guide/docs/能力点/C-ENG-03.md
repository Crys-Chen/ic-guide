# 实验测量与误差分析

- 能力 ID：`C-ENG-03`
- 类型：公共能力
- 修读要求：公共推荐
- 建议窗口：综合创作与迁移（可按兴趣提前或延后）
- 所属领域：工程与科研
- 参考投入：20 小时（不是学期配额）
- 先修能力：[模拟电子技术](./C-CIR-02.md)、[信号与系统](./C-CIR-04.md)

## 学习成果

- 能安全使用电源、万用表、信号源和示波器完成基础测量
- 能选择带宽、采样、探头、接地和触发设置并识别测量扰动
- 能报告不确定度、重复性、校准与理论偏差

## 验收

### 产物

一份放大器增益带宽实测报告，含原始数据、仪器设置、不确定度和误差预算

### 合格标准

每个关键测点至少重复 3 次；原始数据含仪器型号、探头、带宽、采样率和校准日期；不确定度传播可复算，理论值与实测值之差落在合成不确定度内或有定量解释。
