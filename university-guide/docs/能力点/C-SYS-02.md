# 数据结构与算法

- 能力 ID：`C-SYS-02`
- 类型：公共能力
- 修读要求：公共推荐
- 建议窗口：基础工具箱（可按兴趣提前或延后）
- 所属领域：软件与系统
- 参考投入：26 小时（不是学期配额）
- 先修能力：[C 与 Python 编程](./C-SYS-01.md)

## 学习成果

- 能实现数组、链表、栈、队列、树、哈希表和图的核心操作
- 能用渐近复杂度比较排序、搜索和图算法
- 能针对数据规模、内存与访问模式选择并验证算法

## 验收

### 产物

一个含至少六种数据结构、复杂度说明和自动测试的算法实现仓库

### 合格标准

至少 6 种数据结构的插入、删除、查找和边界行为均有测试；每种实现通过不少于 1000 次随机操作对照测试；规模扩大 10 倍时的实测增长趋势与声明复杂度相符。
