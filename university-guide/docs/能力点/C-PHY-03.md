# 半导体物理

- 能力 ID：`C-PHY-03`
- 类型：公共能力
- 修读要求：公共推荐
- 建议窗口：IC 公共核心（可按兴趣提前或延后）
- 所属领域：物理与器件
- 参考投入：24 小时（不是学期配额）
- 先修能力：[量子与固体物理基础](./C-PHY-02.md)、[概率统计](./C-MATH-03.md)

## 学习成果

- 能计算载流子浓度、费米能级、漂移扩散与复合生成
- 能解释掺杂、温度和电场对材料电学性质的影响
- 能由 Poisson 方程和连续性方程建立简单半导体结构模型

## 验收

### 产物

一个计算不同掺杂与温度下载流子浓度、费米能级和电导率的可复现笔记

### 合格标准

至少覆盖 3 个掺杂浓度和 3 个温度；各工况电荷中性残差不超过总掺杂量的 1%；曲线单位完整，且能解释本征、非简并与简并近似的适用范围。
