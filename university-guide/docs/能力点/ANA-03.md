# RF 与毫米波收发前端

- 能力 ID：`ANA-03`
- 类型：专业能力
- 修读要求：路线推荐
- 建议窗口：方向探索与深化（可按兴趣提前或延后）
- 所属领域：模拟与射频电路
- 参考投入：28 小时（不是学期配额）
- 先修能力：[概率统计](./C-MATH-03.md)、[信号与系统](./C-CIR-04.md)、[模拟集成电路](./C-CIR-05.md)、[CMOS 模拟单元与偏置](./ANA-01.md)

## 学习成果

- 使用 S 参数、Smith 圆图、噪声系数和线性度指标分析 RF 网络
- 完成 LNA、混频器、振荡器或功放的基本拓扑选择与匹配
- 建立接收机级联增益、噪声和 IIP3 预算

## 验收

### 产物

一个目标频段 RF 前端的系统预算与至少一个晶体管级模块仿真

### 合格标准

S 参数、NF、稳定因子和线性度均按同一参考阻抗验证，并解释版图寄生影响
