# 论文与设计复现

- 能力 ID：`C-ENG-06`
- 类型：公共能力
- 修读要求：公共推荐
- 建议窗口：综合创作与迁移（可按兴趣提前或延后）
- 所属领域：工程与科研
- 参考投入：24 小时（不是学期配额）
- 先修能力：[Linux 与 Git 工程环境](./C-ENG-01.md)、[电路与器件仿真](./C-ENG-02.md)、[文献检索与引用管理](./C-ENG-04.md)、[技术写作与表达](./C-ENG-05.md)

## 学习成果

- 能从论文提取主张、数据、方法、超参数和隐含假设
- 能建立可追踪环境并复现至少一个核心图表或指标
- 能区分复现失败、结果差异和原结论不成立并如实报告

## 验收

### 产物

一个带锁定环境、数据说明、运行脚本、复现结果和差异分析的复现包

### 合格标准

在全新环境中一条命令可生成目标图表或指标；核心数值与论文结果相差不超过 5% 或有逐项证据解释；数据来源、许可、哈希、随机种子和失败尝试全部记录。
