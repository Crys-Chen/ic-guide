# 技术写作与表达

- 能力 ID：`C-ENG-05`
- 类型：公共能力
- 修读要求：公共推荐
- 建议窗口：综合创作与迁移（可按兴趣提前或延后）
- 所属领域：工程与科研
- 参考投入：18 小时（不是学期配额）
- 先修能力：[文献检索与引用管理](./C-ENG-04.md)

## 学习成果

- 能围绕受众、目的和证据组织技术报告、图表与摘要
- 能用清晰、准确、可追溯的语言描述方法和结果
- 能通过同伴评审迭代书面报告和口头展示

## 验收

### 产物

一篇经两轮评审修订的四页技术报告及一个八分钟配音演示

### 合格标准

完成两轮有记录的同伴评审并逐条处置意见；报告中每张图均有单位、图注和来源，引用可追踪；统一 rubric 得分不低于 80%，演示时长为 8 分钟正负 30 秒。
