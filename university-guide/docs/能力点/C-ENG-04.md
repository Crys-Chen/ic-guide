# 文献检索与引用管理

- 能力 ID：`C-ENG-04`
- 类型：公共能力
- 修读要求：公共推荐
- 建议窗口：基础工具箱（可按兴趣提前或延后）
- 所属领域：工程与科研
- 参考投入：18 小时（不是学期配额）
- 先修能力：无

## 学习成果

- 能把研究问题拆成关键词、同义词、布尔式和检索边界
- 能在学术数据库中迭代检索并按证据质量筛选来源
- 能用统一格式管理引用、去重并记录检索过程

## 验收

### 产物

一份可复查的检索式、筛选流程图、20 篇注释书目和引用库导出文件

### 合格标准

至少在 2 个数据库运行并保存完整检索式与日期；去重后含不少于 20 篇来源，每篇有纳入理由和证据等级；引用库无重复、缺作者/年份或断裂附件链接。
