# 微积分与工程建模

- 能力 ID：`C-MATH-01`
- 类型：公共能力
- 修读要求：公共推荐
- 建议窗口：入门与试做（可按兴趣提前或延后）
- 所属领域：数学
- 参考投入：24 小时（不是学期配额）
- 先修能力：无

## 学习成果

- 能用极限、导数和积分描述连续时间电路与器件中的变化率和累积量
- 能建立一阶工程模型并检查量纲、边界条件与结果合理性
- 能用数值或符号工具验证手算结论

## 验收

### 产物

一份含建模假设、推导、数值验证和误差讨论的 RC 充放电微积分报告

### 合格标准

方程量纲与初始/边界条件全部正确；闭式解与数值解在至少 50 个采样点的最大相对误差不超过 5%；明确列出至少 2 项模型假设及适用边界。
