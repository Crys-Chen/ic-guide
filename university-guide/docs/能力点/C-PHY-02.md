# 量子与固体物理基础

- 能力 ID：`C-PHY-02`
- 类型：公共能力
- 修读要求：公共推荐
- 建议窗口：基础工具箱（可按兴趣提前或延后）
- 所属领域：物理与器件
- 参考投入：24 小时（不是学期配额）
- 先修能力：[微积分与工程建模](./C-MATH-01.md)、[线性代数](./C-MATH-02.md)、[电磁学](./C-PHY-01.md)

## 学习成果

- 能解释波函数、测量、能级、隧穿和量子统计的基本含义
- 能由周期势、能带和费米能级说明金属、绝缘体与半导体的差异
- 能把微观模型与器件尺度下的载流子行为联系起来

## 验收

### 产物

一份从无限深势阱到能带形成的推导笔记，并用数值本征值计算验证前三个能级

### 合格标准

前三个数值能级与解析值相对误差均不超过 1%；波函数归一化误差和两两内积绝对值均不超过 1e-3；能用能带与费米能级正确区分三类材料。
