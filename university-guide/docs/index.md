# 大学 IC 培养指南

本指南帮你从兴趣或项目出发，找到所需能力、反向补齐先修，并用可观察的产物证明已经学会。它不规定某学期必须学什么。

!!! info "推荐用法"
    先阅读[自由探索路线](自由探索路线.md)，选择“兴趣优先”、“项目优先”或“基础优先”。不需要先学完 32 个公共点；从当下问题出发，只补阻塞你的先修。

## 交付内容

- [现站全面解读与审计](现站审计.md)：内容、体验、技术、治理四维分析。
- [自由探索路线](自由探索路线.md)：三种入口、五个非学期建议窗口与项目反向补先修的循环。
- [56 个能力点](能力点/index.md)：32 个公共能力点加 24 个方向能力点。
- [六条专业路线](专业路线/index.md)：覆盖原站 17 个科研方向。
- [视频资源库](视频资源/index.md)：每个能力点一项主资源和一项备选资源。
- [资源筛选方法](资源筛选方法.md)：搜索优先级、评分量表与核验动作。
- [复旦 2025 培养方案映射](复旦培养方案映射.md)：展示学校课程如何映射到通用能力框架。
- [上游改进包](上游改进.md)：可转化为原站 Issue 或补丁的建议。
- [实施与迭代计划](实施与迭代计划.md)：已完成阶段、发布流程、上游拆分与维护节奏。
- [维护手册](维护手册.md)：数据、链接与内容复核流程。
- [实施验收报告](验收报告.md)：实际数量、构建、内链、抽查证据与环境受限项。

## 完成标准

完成某个能力点不等于“看完视频”。每个能力页都给出可观察的学习成果和验收产物；只有能够独立解释、计算、实现或验证，才算完成。
